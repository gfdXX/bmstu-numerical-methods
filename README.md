## Семестр 2. Одномерная минимизация

Целевая функция на отрезке [0, 1]:

```
f(x) = arcsin((35x² − 30x + 9) / 20) + cos((10x³ + 185x² + 340x + 103) / (50x² + 100x + 30)) + 0.5
```

| Работа | Файл | Метод |
|---|---|---|
| [ЛР1](sem2-one-dim-optimization/lab1-bitwise-search) | `lab_01.m` | поразрядный поиск |
| [ЛР2](sem2-one-dim-optimization/lab2-golden-section) | `lab_02.m` | золотое сечение |
| [ЛР3](sem2-one-dim-optimization/lab3-parabola) | `lab_03.m` | метод парабол со стартом от золотого сечения |
| [ЛР4](sem2-one-dim-optimization/lab4-newton) | `lab_04.m` | модифицированный метод Ньютона с конечно-разностными производными, сравнение с `fminbnd` |

Каждый скрипт рисует график функции, найденный минимум и последовательность приближений (её вывод отключается флагом в начале функции).
